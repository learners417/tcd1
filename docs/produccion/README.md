# Producción

Todo lo que hace falta para grabar las 43 piezas. Es la contracara del paquete de
especificación: ahí está cómo funciona la app, acá está qué se dice frente a la
cámara.

| Archivo | Qué es |
|---|---|
| `13-GUIONES-DE-RODAJE.md` | Las cuatro jornadas. Las piezas de oficina escritas palabra por palabra |
| `14-AUDITORIA-VIDEOS.md` | Qué hacer con cada grabación que ya existe |
| `oficina-hoja-de-rodaje.html` | La jornada de oficina, para abrir en el teléfono mientras grabás |
| `camino-90-dias-definitivo.html` | El camino completo, versión visual |
| `camino-90-dias-revision-integral.html` | Calendario día por día, accesos y evidencias |
| `dojo-protocolo-progresion.html` | El Dojo, las tres aperturas y los once cinturones |

Los cuatro HTML se abren en cualquier navegador y están pensados para leer desde
el teléfono. **El de oficina, en particular, se usa mientras se graba.**
